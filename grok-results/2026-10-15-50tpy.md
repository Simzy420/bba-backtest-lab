## What changed vs 25/yr
- Cap never binds for R4-C, R3, Trend MA cross, RSI mean-reversion, BTC hold: identical picks and results.
- Donchian: picked faster n=20 in 3 late windows -> +100.9% (was +89.5%), DD 24.4% still fails Shield.
- Breakout >200MA 1.0x: picked n=20 more often -> return fell to +34.6% (from +38.7%), cost/gross rose 32.0% -> 35.9%; DD dipped to 19.5% so it scrapes a PASS, but at 25.2 trades/yr it would fail the old 25 cap.
- Breakout ATR-scaled: faster picks in 5 windows -> +39.8% (from +41.7%), Sharpe 0.86 -> 0.81, DD 13.2%. Passes; 24.8/yr.

## Verdict
Allowing more trades does not reliably help after fees. It only changed picks in the three breakout/channel strategies; it helped Donchian (still fails on drawdown) and made both breakout versions slightly worse with higher cost share. Note Casey's recorded standing rule (Sep 16 notes) is ~15 trades/yr; both breakout variants (~25/yr) and Donchian exceed that.
